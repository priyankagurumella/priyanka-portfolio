01 Completed

ForensicAI

AI • Deepfake & Fake News Detection

An AI-powered system that detects fake news and manipulated media in one place. It works in two phases. For text, a TF-IDF and Passive Aggressive Classifier model checks news articles and reaches about 99.6% accuracy. For images, an EfficientNet-B0 deep learning model trained with transfer learning identifies deepfakes with about 83% validation accuracy, and Grad-CAM heatmaps show which regions influenced the decision so the result can be explained. The back end is built with Flask and the front end is deployed on GitHub Pages.

Python Flask PyTorch Scikit-learn EfficientNet-B0 Grad-CAM NLP

02 In progress

Civic Problem Reporter

Civic Tech • Multi-App System

A two-app platform that connects citizens with the people who fix local problems. In the User app, citizens report an issue with a photo and location. In the Agent app, field agents receive the task, resolve it, and upload an after photo. An AI vision model (Llama 3.2 Vision on Cloudflare Workers AI) detects the issue from the photo and audits the before and after images to confirm it was truly resolved. The platform also includes push notifications, geo-tagging, secure login with JWT, image uploads, reward points for active citizens, and a web admin dashboard.

React Native Expo Node.js Express PostgreSQL Cloudflare Workers AI JWT
